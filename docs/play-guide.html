🤝 친구 초대

친구를 초대하고 보석을 받으세요! 함께하면 더 재밌어요.

📨 초대 방법

  1. /invite code로 내 초대 코드 확인
  2. 친구에게 코드 공유
  3. 친구가 /invite use [코드]로 입력
  4. 보상 자동 지급! 💎

💎 보상 안내

초대한 사람

  • 친구 가입 시 → 보석 30개
  • 친구 Lv.10 달성 → 보석 50개
  • 친구 Lv.30 달성 → 보석 100개

최대 180 보석 획득!

초대받은 친구

  • 가입 시 → 골드 500
  • Lv.10 달성 → 보석 20개

시작부터 혜택!

명령어

  • /invite code - 내 초대 코드 확인
  • /invite use [코드] - 초대 코드 사용 (Lv.5 이하)
  • /invite status - 초대 현황 확인
  • /invite ranking - 이달의 초대왕 🏆
