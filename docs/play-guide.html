⚔️ 전투 시스템

턴제 전투로 몬스터를 처치하고 경험치와 골드를 획득하세요.

💥 크리티컬 시스템

20% 확률로 크리티컬! 2배 데미지를 입힙니다.

💨 회피 시스템

15% 확률로 적의 공격을 회피합니다.

🔥 연승 보너스

연속 승리 시 추가 보상! 최대 2배까지.

✨ 희귀 몬스터

10% 확률로 등장, 3배 경험치 보상!

주요 명령어

  • /explore - 필드 탐험 및 전투
  • /boss - 보스 몬스터 도전
  • /fieldboss - 필드 보스 정보 확인
  • /arena - PvP 아레나

🔨 생산 시스템

채집과 제작으로 아이템을 만들고 판매하세요.

⛏️ 채집

목재, 광석, 허브 등 원자재를 수집합니다.

🔧 제작

원자재로 장비와 포션을 제작합니다.

📈 생산 직업

대장장이, 연금술사, 요리사 등 전문화!

🎯 생산 스킬

숙련도를 올려 더 좋은 아이템 제작!

주요 명령어

  • /gather - 자원 채집 시작
  • /craft - 아이템 제작
  • /resources - 보유 자원 확인
  • /production_skills - 생산 스킬 확인

📦 자원 & 채집

22종의 자원을 채집하고 제작에 활용하세요!

🪨 광물 (광부)

철광석 → 구리광석 → 은광석 → 금광석 → 💎보석

🌿 허브 (약초꾼)

허브 → 약초 → 희귀 약초 → ✨마법 허브

🪵 목재 (벌목꾼)

목재 → 단단한 목재 → 희귀 목재 → 마법 목재

🎣 어획물 (어부)

물고기 → 희귀 물고기 → 해산물 → 🫧진주

🐾 사냥품 (사냥꾼)

가죽 → 고기 → 모피 → 뼈

🔨 제작 직업

대장장이 · 연금술사 · 재봉사 · 요리사
