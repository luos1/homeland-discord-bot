# 레이드 시스템 설계

## 핵심 컨셉

**"플레이어 스킬 기반 협동 전투 시스템"**

- 스탯/장비로 이기는 것이 아니라, 공대장의 전략과 컨트롤 실력으로 승부
- WoW 불성 레이드 느낌: 협동, 역할 분담, 고정 공략법
- 웹 기반 실시간 전투 (Discord는 모집/입장/보상만)

## 게임 루프

```
개인 육성 (사냥, 생산, 장비 강화)
    ↓
레이드 입장 자격 획득 (레벨, 장비 조건)
    ↓
Discord 커뮤니티 파티 모집 (탱/딜/힐 역할)
    ↓
웹 기반 레이드 전투 (채스판 배치 + 실시간 스킬 컨트롤)
    ↓
레이드 전용 보상 획득 (고급 장비, 레어 재료)
    ↓
더 높은 난이도 레이드 도전 (반복)
```

## 1. 지형 시스템

### 채스판 크기 (보스 등급별)
```
일반 보스:  3x3 (9칸)   - 단순 지형, 기본 메커니즘
영웅 보스:  4x5 (20칸)  - 중간 복잡도, 장애물 추가
레이드 보스: 6x6 (36칸) - 복잡한 지형, 다중 메커니즘
```

### 지형 타입
| 타일 | 이름 | 효과 |
|------|------|------|
| 🟩 | 평지 | 기본 지형, 효과 없음 |
| 🟦 | 물웅덩이 | 이동속도 -50%, 번개 피해 +100% |
| 🟥 | 용암 | 매턴 최대HP 5% 화상 피해 |
| 🟨 | 고지대 | 원거리 공격력 +20%, 근거리 공격 불가 |
| ⬛ | 장애물 | 이동/시야 차단, 통과 불가 |
| ✨ | 버프존 | 보스별 특수 효과 (예: 공격력 +30%, 회복 등) |
| 🌪️ | 함정 | 특정 턴마다 활성화, 피해/디버프 |

## 2. 공대장 시스템

### 공대장 = RTS 플레이어
**핵심 메커니즘: 공대장이 모든 공대원을 직접 컨트롤**

- 공대원들은 자기 캐릭터를 조종하지 **않음**
- 공대장이 8명의 캐릭터를 전부 실시간 컨트롤 (스타크래프트처럼)
- 공대원들은 채팅으로 조언/피드백만 가능
- 진짜 "공대장의 실력"이 승패를 결정

### 공대장의 능력 (= 플레이어 스킬)
게임 내 스탯이 아닌, **실제 플레이어의 능력**으로 승부:

1. **캐릭터 이해**
   - 공대원 8명의 직업/스킬 전부 파악
   - 장비/스탯 기반 역할 분배
   - 시너지 조합 구성

2. **공략법 파훼**
   - 보스 패턴 분석
   - 지형 활용 전략
   - 타이밍 최적화

3. **전략 수립**
   - 8명 배치 최적화
   - 스킬 로테이션 계획 (8명 분)
   - 위기 대응 플랜

4. **필요한 컨트롤 (RTS 수준)**
   - 8명의 스킬을 실시간 발동
   - 8명의 이동 명령 동시 관리
   - 타겟팅 변경 (누가 보스 때릴지, 누가 힐할지)

## 3. 전투 메커니즘

### 타일 기반 턴제 전략 게임
- **턴 순서**: 공대원 → 보스 → 다음 턴
- **타임 리미트**: 보스마다 **최대 턴 수** 설정 (예: 고블린 왕 30턴)
- **광폭화**: 최대 턴 초과 시 보스 광폭화 (공격력 2배, 전체 공격)
- **페이즈 시스템**: 보스 HP 구간별 패턴 변화

### 턴 진행 방식
```
턴 1:
1. 공대장이 8명의 행동을 순서대로 명령
   - 탱커1: (1,1)로 이동
   - 힐러1: 대기
   - 딜러1: 보스 공격
   - 딜러2: (2,2)로 이동
   - ... (8명 전부)
2. [턴 종료] 버튼 클릭
3. 모든 공대원 행동 동시 실행
4. 보스 턴: 패턴에 따라 공격
5. 턴 2 시작
```

### 타임 리미트 시스템
```javascript
{
  boss: "고블린 왕",
  maxTurns: 30,  // 30턴 이내 클리어 필수
  enrageEffect: {
    attackMultiplier: 2.0,
    newSkill: "전체 강타",  // 광폭화 전용 스킬
    message: "⚠️ 고블린 왕이 광폭화했습니다!"
  }
}
```

**긴장감 요소**:
- 남은 턴: 25턴 → "여유있음"
- 남은 턴: 10턴 → "⚠️ 서둘러야 합니다!"
- 남은 턴: 5턴 → "🚨 광폭화 임박!"
- 남은 턴: 0턴 → "💀 광폭화! 공격력 2배!"

### 공대장 컨트롤 방식 (턴제)

**턴 시작 → 8명 명령 → 턴 종료 → 실행**

```javascript
// 공대장의 턴 진행 과정

턴 12 시작:

1. 탱커1 선택
   공대장 클릭: 탱커1
   공대장 클릭: [이동] 버튼
   공대장 클릭: (2, 3) 타일
   → 명령 큐에 추가: "탱1 → (2,3) 이동"

2. 힐러1 선택
   공대장 클릭: 힐러1
   공대장 클릭: [스킬] 버튼
   공대장 클릭: [💚 회복]
   공대장 클릭: 탱커1
   → 명령 큐에 추가: "힐1 → 탱1 회복"

3. 딜러1, 2, 3 선택 (순서대로)
   공대장: 각 딜러 선택 → [공격] → 보스 클릭
   → 명령 큐에 추가: "딜1,2,3 → 보스 공격"

4. 나머지 공대원 명령 (총 8명)
   ...

5. 공대장 클릭: [✅ 턴 종료] 버튼
   → 서버로 명령 큐 전송

6. 서버가 모든 명령 동시 실행:
   - 탱1 이동 (2,3)
   - 힐1 회복 → 탱1 HP +300
   - 딜1,2,3 공격 → 보스 HP -1500
   ...

7. 보스 턴 자동 실행:
   - 패턴에 따라 공격 (예: 화염 브레스 → 탱1 HP -500)

8. 턴 13 시작
```

**명령 큐 시스템**:
```javascript
{
  turn: 12,
  commands: [
    { characterId: "tank1", action: "move", target: { x: 2, y: 3 } },
    { characterId: "healer1", action: "skill", skillId: "heal", target: "tank1" },
    { characterId: "dps1", action: "attack", target: "boss" },
    { characterId: "dps2", action: "attack", target: "boss" },
    { characterId: "dps3", action: "skill", skillId: "fire-arrow", target: "boss" },
    { characterId: "healer2", action: "wait" },  // 대기
    { characterId: "dps4", action: "attack", target: "boss" },
    { characterId: "dps5", action: "move", target: { x: 1, y: 0 } }
  ]
}
```

**공대원의 역할**:
- ❌ 자기 캐릭터 조종 안 함
- ✅ 채팅으로 조언 ("탱커 HP 위험!", "2페이즈 용암 조심!")
- ✅ 명령 큐 확인하면서 제안 ("힐러2도 회복 쓰는 게 나을 것 같아요")
- ✅ 전투 후 피드백 (공대장 평가, MVP 투표)
- ✅ 공략 토론 ("다음엔 이렇게 해볼까요?")

**턴제의 장점**:
- 공대장이 천천히 전략 짤 수 있음 (실수 방지)
- 공대원들이 명령 큐 보면서 조언 가능
- 타임 리미트로 긴장감 유지 (무한 고민 방지)

### DB 스키마 추가
```prisma
model Raid {
  id          String   @id @default(cuid())
  bossId      String
  difficulty  String   // "normal" | "heroic"
  leaderUserId String
  status      String   // "recruiting" | "in-progress" | "completed" | "failed"
  participants RaidParticipant[]
  startTime   DateTime?
  endTime     DateTime?
  createdAt   DateTime @default(now())
}

model RaidParticipant {
  id          String   @id @default(cuid())
  raidId      String
  raid        Raid     @relation(fields: [raidId], references: [id])
  userId      String
  characterId String
  role        String   // "tank" | "healer" | "dps"
  position    Json?    // { x: 0, y: 0 }
  joinedAt    DateTime @default(now())
}

model RaidBoss {
  id          String   @id @default(cuid())
  name        String
  difficulty  String
  mapSize     Json     // { width: 6, height: 6 }
  terrain     Json     // [[tile, tile, ...], ...]
  patterns    Json     // 보스 패턴 JSON
  hp          Int
  rewards     Json     // 드랍 테이블
}

model RaidClear {
  id          String   @id @default(cuid())
  userId      String
  bossId      String
  difficulty  String
  clearedAt   DateTime @default(now())
  
  @@unique([userId, bossId, difficulty])
}
```

## 10. 차별화 포인트

### 기존 RPG 봇과의 차이
| 기존 봇 | Homeland 레이드 |
|---------|----------------|
| 스탯/장비로 승부 | 플레이어 스킬로 승부 |
| 버튼 클릭만 | 타일 기반 턴제 전략 게임 |
| 개인 플레이 | 협동 플레이 필수 |
| 단순 반복 | 학습 가능한 고정 공략 |
| Discord 텍스트만 | 웹 UI (시각적) |

### 턴제 전략 + 협동의 독특한 조합
- **공대장**: XCOM/Fire Emblem처럼 8명 턴제 컨트롤
- **공대원**: 명령 큐 보면서 조언 ("힐러2도 회복 쓰는 게 나을 듯!")
- **역할 분담**: 공대장은 전략 수립, 공대원은 실시간 조언
- **타임 어택**: 최대 턴 내에 클리어 실패 시 광폭화 (긴장감 ↑)
- **전략성**: 턴마다 8명 배치/스킬 최적화 필요
- **성취감**: 타임 리미트 안에 협업으로 클리어

### 진짜 MMORPG 경험
- **실패가 재미있음**: 와이프 후 전략 회의 → 개선 → 재도전
- **커뮤니케이션 자연 발생**: 공략 논의, 피드백, 칭찬
- **공대장의 성장**: 평점 시스템으로 실력 인정
- **공략 문화 형성**: 라이브러리, 공유, 토론
- **소셜 관계 구축**: 같이 고생한 공대원 = 친구
