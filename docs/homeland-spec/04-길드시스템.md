# 04. 길드 시스템

## 개요
플레이어들이 협동하여 목표를 달성하는 소셜 시스템. 길드 창고, 자금, B2B 거래, 월드 납품 기능 제공.

## 1. 길드 기본 시스템

### 1.1 길드 생성
- **비용:** 50,000 골드
- **최소 레벨:** Lv.10
- **길드명:** 2-20자, 한글/영문/숫자 허용
- **길드 태그:** [TAG] 2-5자
- **최대 인원:** 기본 20명 (확장 가능)
- **마스터 권한:** 생성자가 자동 마스터

### 1.2 길드 가입/탈퇴
- **가입:**
  - 길드 목록에서 선택
  - 마스터/부마스터 승인 필요
  - 길드당 1캐릭터만 가입
- **탈퇴:**
  - 자유 탈퇴 (쿨다운 24시간)
  - 마스터는 다른 멤버에게 양도 후 탈퇴

### 1.3 길드 직위
- **마스터:** 모든 권한
- **부마스터:** 멤버 관리, 창고 관리
- **일반:** 기본 멤버

### 1.4 길드 정보
- 길드명, 태그, 마스터
- 멤버 수 / 최대 인원
- 길드 레벨 (멤버 활동으로 상승)
- 길드 골드
- 창고 슬롯 수

## 2. 길드 창고

### 2.1 기본 정보
- **초기 슬롯:** 50칸
- **확장:** 길드 레벨당 +10칸
- **보관 가능:** 자원, 장비, 소비템

### 2.2 권한 시스템
- **일반:** 보관만 가능
- **부마스터 이상:** 보관/인출 가능

### 2.3 보관/인출 로그
- 누가, 언제, 무엇을, 얼마나
- 최근 50개 기록 표시

## 3. 길드 자금

### 3.1 길드 골드
- **획득:**
  - 멤버 기부
  - 월드 납품 보상
  - B2B 거래 수수료 (1%)
- **사용:**
  - 창고 확장
  - 멤버 한도 확장
  - 월드 납품 구매

### 3.2 기부 시스템
- 멤버가 개인 골드 → 길드 골드로 기부
- 기부 랭킹 (주간/전체)
- 기부 보상: 길드 포인트 (추후 확장)

## 4. 길드 거래소 (B2B)

### 4.1 개요
- 길드 간 대량 거래
- 개인 거래소보다 낮은 수수료 (5% → 3%)
- 최소 거래량: 10개 이상

### 4.2 거래 항목
- **자원:** 광석, 나무, 가죽, 허브, 보석
- **장비:** 희귀 등급 이상만
- **소비템:** 포션, 버프 아이템

### 4.3 거래 흐름
1. 판매 길드: 창고에서 물품 등록
2. 구매 길드: 길드 골드로 구매
3. 거래 성사 시: 수수료 3% 차감
4. 구매 길드 창고로 자동 이동

## 5. 월드 납품

### 5.1 개요
- 서버 전체가 협력하는 이벤트
- 특정 아이템 대량 납품 → 서버 전체 버프

### 5.2 납품 주기
- **매주 월요일 00:00 갱신**
- 총 3개 슬롯 (자원 2개, 장비 1개)

### 5.3 납품 항목 예시
| 슬롯 | 항목 | 목표량 | 보상 |
|------|------|--------|------|
| 1 | 철광석 | 10,000개 | 전체 유저 골드 획득 +10% (7일) |
| 2 | 고급 가죽 | 5,000개 | 전체 유저 자원 드롭률 +15% (7일) |
| 3 | 희귀 무기 | 500개 | 전체 유저 경험치 +20% (7일) |

### 5.4 기여도 시스템
- 길드별 납품량 추적
- 상위 3개 길드: 추가 보상 (길드 골드)
- 개인 납품량도 추적 → 길드 내 랭킹

## 7. DB 스키마

### 7.1 Guild
```prisma
model Guild {
  id          Int       @id @default(autoincrement())
  name        String    @unique
  tag         String    @unique // [TAG]
  masterId    String    // Character.id
  level       Int       @default(1)
  gold        Int       @default(0)
  memberLimit Int       @default(20)
  createdAt   DateTime  @default(now())
  updatedAt   DateTime  @updatedAt
  
  members     GuildMember[]
  warehouse   GuildWarehouseItem[]
  trades      GuildTrade[]
  contributions GuildContribution[]
}
```

### 7.2 GuildMember
```prisma
model GuildMember {
  id          Int       @id @default(autoincrement())
  guildId     Int
  characterId String    @unique
  role        String    // master, officer, member
  joinedAt    DateTime  @default(now())
  
  guild       Guild     @relation(fields: [guildId], references: [id])
  character   Character @relation(fields: [characterId], references: [id])
  
  @@unique([guildId, characterId])
}
```

### 7.3 GuildWarehouseItem
```prisma
model GuildWarehouseItem {
  id          Int       @id @default(autoincrement())
  guildId     Int
  itemType    String    // resource, equipment, consumable
  itemId      Int?      // 참조 ID
  itemData    Json      // 아이템 상세 정보
  quantity    Int       @default(1)
  depositedBy String    // Character.id
  depositedAt DateTime  @default(now())
  
  guild       Guild     @relation(fields: [guildId], references: [id])
}
```

### 7.4 GuildTrade
```prisma
model GuildTrade {
  id            Int       @id @default(autoincrement())
  sellerGuildId Int
  buyerGuildId  Int?
  itemType      String
  itemData      Json
  quantity      Int
  pricePerUnit  Int
  totalPrice    Int
  status        String    // active, completed, cancelled
  createdAt     DateTime  @default(now())
  completedAt   DateTime?
  
  sellerGuild   Guild     @relation(fields: [sellerGuildId], references: [id])
}
```

### 7.5 WorldContribution
```prisma
model WorldContribution {
  id          Int       @id @default(autoincrement())
  weekKey     String    // 2026-W08
  slotIndex   Int       // 0, 1, 2
  itemType    String
  itemName    String
  targetQty   Int
  currentQty  Int       @default(0)
  rewardDesc  String
  status      String    // active, completed
  startedAt   DateTime  @default(now())
  completedAt DateTime?
  
  @@unique([weekKey, slotIndex])
}
```

### 7.6 GuildContribution
```prisma
model GuildContribution {
  id                    Int       @id @default(autoincrement())
  worldContributionId   Int
  guildId               Int
  characterId           String
  quantity              Int
  contributedAt         DateTime  @default(now())
  
  guild                 Guild     @relation(fields: [guildId], references: [id])
}
```
