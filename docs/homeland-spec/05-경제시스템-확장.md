## 1. NPC 상점 동적 가격 시스템

### 1.1 개념
> **공급량에 따라 NPC 매입/판매 가격 실시간 변동**

```
공급 많음 → NPC 매입가 ↓ → 플레이어끼리 거래 유도
공급 적음 → NPC 매입가 ↑ → 시장 안정화
```

### 1.2 가격 계산 공식

```javascript
// 기준 가격 (base price)
const basePrice = RESOURCE_BASE_PRICES[resourceType];

// 서버 총 공급량 (최근 24h)
const totalSupply = await getTotalSupply(resourceType, '24h');

// 수요량 추정 (최근 24h 거래량)
const totalDemand = await getTotalDemand(resourceType, '24h');

// 공급/수요 비율
const supplyDemandRatio = totalSupply / totalDemand;

// 가격 배율 계산
let priceMultiplier;
if (supplyDemandRatio > 2.0) {
  // 과잉 공급 → 가격 하락 (최대 -50%)
  priceMultiplier = 0.5 + (1.0 / supplyDemandRatio);
} else if (supplyDemandRatio < 0.5) {
  // 공급 부족 → 가격 상승 (최대 +100%)
  priceMultiplier = 1.0 + (1.0 - supplyDemandRatio);
} else {
  // 정상 범위
  priceMultiplier = 1.0;
}

// 최종 NPC 매입가
const npcBuyPrice = Math.floor(basePrice * priceMultiplier * 0.7); // 기준가의 70%

// 최종 NPC 판매가
const npcSellPrice = Math.floor(basePrice * priceMultiplier * 1.3); // 기준가의 130%
```

## 3. 세금/수수료 조정 시스템

### 3.1 현재 고정 수수료
- 거래소: 10%
- 골드↔젬: 5%

### 3.2 동적 수수료 시스템

```javascript
// 거래량 기반 수수료 조정
const dailyTradeVolume = await getDailyTradeVolume();

let feeRate;
if (dailyTradeVolume > 1000000) {
  // 활성화된 경제 → 수수료 인하 (최소 3%)
  feeRate = Math.max(0.03, 0.10 - (dailyTradeVolume / 10000000));
} else if (dailyTradeVolume < 100000) {
  // 침체된 경제 → 수수료 유지 (10%)
  feeRate = 0.10;
} else {
  // 정상 경제
  feeRate = 0.07;
}
```

## 5. 가격 추천 시스템 (AI 기반)

### 5.1 개념
> **과거 거래 데이터 분석 → 적정 가격 추천**

### 5.2 추천 알고리즘

```javascript
// 최근 7일 평균가
const avg7d = await getAvgPrice(itemKey, '7d');

// 최근 24h 평균가
const avg24h = await getAvgPrice(itemKey, '24h');

// 최근 거래 10건 평균
const recentAvg = await getRecentAvgPrice(itemKey, 10);

// 가격 추세
const trend = (avg24h - avg7d) / avg7d; // +0.1 = 10% 상승

// 추천가 계산
let recommendedPrice;
if (trend > 0.2) {
  // 급등장 → 평균보다 높게
  recommendedPrice = Math.floor(avg24h * 1.1);
} else if (trend < -0.2) {
  // 급락장 → 평균보다 낮게
  recommendedPrice = Math.floor(avg24h * 0.9);
} else {
  // 정상 → 최근 평균
  recommendedPrice = recentAvg;
}

// 신뢰도
const confidence = calculateConfidence(itemKey); // 거래량 기반
```
