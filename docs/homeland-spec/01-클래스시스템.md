## 🛡️ 경비 클래스 상세

> 탱커 + 포탑 변신, 자면서 돈 버는 유일한 클래스

```
[일반 모드] 🛡️ 탱커 → 방어/어그로/파티 서포트
[경비 모드] 🗼 포탑 변신 → 고정 위치 자동 방어
```

### 특징
- **이중 역할**: 탱커(이동) ↔ 포탑(고정)
- **오프라인 가치**: 경비 모드 = 접속 안 해도 일함
- **위치 전략**: 어디 배치하냐가 중요
- **고용 수요**: "우리 농장에 경비 서줘"

## 🐺 드루이드 클래스 상세

> **유일한 하이브리드**: 전투 + 탈것 생산

### 특징
- **전투**: 변신/소환으로 싸움 **(전투력 약함)**
- **생산**: 탈것 테이밍/브리딩/양육
- **희소가치**: 모든 길드에 필수

### ⚖️ 밸런스
```
전투력: 다른 전투 클래스의 70~80% 수준
보상: 탈것 생산으로 경제력 확보

→ 직접 싸우면 약함
→ 돈 벌어서 장비빨로 커버
→ 또는 서포터/유틸로 활약
```

## MVP 구현 범위 (Discord Bot)

### Phase 1: 전투 클래스 3개
- 🪓 **바바리안** (Warrior 대체)
- 🏹 **아마존** (Ranger 대체)
- 🔮 **소서리스** (Sorcerer 대체)

### Phase 2: 전직 시스템 확장
- 각 클래스별 전직 경로 추가
- 현재: Berserker/Sniper/Archmage (유지)
- 추후: 8개 전투 클래스 전부 구현

### Phase 3: 생산 클래스 (장기)
- 채집/제작 시스템 추가
- 경제 시스템 완성 후 구현
