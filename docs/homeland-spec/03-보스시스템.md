# 보스 시스템 기획서 (Draft)

## 개요

보스 시스템은 일반 몬스터보다 강력한 적과의 전투를 제공합니다.

**보스 종류:**
1. **필드 보스** - 개인 전투용 (솔로)
2. **월드 보스** - 레이드용 (다중 플레이어)

---

## 1. 필드 보스

### 1.1 개요
- **솔로 전투** (1인 전용)
- 일반 전투 시스템 사용
- 더 높은 난이도 & 보상

### 1.2 특징
- 각 지역마다 1~2개 필드 보스
- 높은 HP, 공격력, 방어력
- 특수 스킬 패턴
- 희귀 장비 드롭
- 일일 제한 또는 리스폰 타이머

### 1.3 보상
- 희귀/영웅 등급 장비 확정 드롭
- 대량 골드 & 경험치
- 전설 레시피 재료
- 칭호/업적

### 1.4 예시 (미구현)

**Zone 1 - 초보자 숲:**
- 🐺 **알파 울프** (Lv.10)
  - HP: 300
  - 패턴: 무리 소환, 광폭화
  - 드롭: 희귀 가죽 갑옷

**Zone 2 - 어둠의 동굴:**
- ⚔️ **타락한 기사** (Lv.20)
  - HP: 600
  - 패턴: 방어 태세, 강타
  - 드롭: 영웅 무기

**Zone 3 - 죽음의 산맥:**
- 🐉 **어린 드래곤** (Lv.35)
  - HP: 1200
  - 패턴: 화염 브레스, 비행
  - 드롭: 전설 재료

---

## 2. 월드 보스 (레이드)

### 2.1 개요
- **다중 플레이어 전투** (파티/레이드)
- 별도 레이드 시스템 필요
- 서버 전체 이벤트

### 2.2 특징
- 매우 높은 HP (수만~수십만)
- 복잡한 패턴
- 협동 메커니즘 필요
- 주간/월간 스케줄
- 서버 전체 알림

### 2.3 레이드 메커니즘 (미기획)

**시스템 요구사항:**
- 파티 시스템
- 실시간 동기화
- 역할 시스템 (탱/딜/힐)
- 공격 순서 조율
- 보상 분배

**고려 사항:**
- Discord 봇 특성상 실시간 협동 어려움
- 턴제 기반 레이드?
- 비동기 기여도 시스템?

### 2.4 예시 (미구현)

**주간 보스:**
- 🐲 **고대 드래곤 바하무트**
  - HP: 50,000
  - 참여: 최대 20명
  - 시간: 매주 토요일 20:00
  - 보상: 전설 장비, 희귀 재료

**월간 보스:**
- 👑 **마왕 아자젤**
  - HP: 200,000
  - 참여: 서버 전체
  - 시간: 매월 마지막 주 일요일
  - 보상: 신화 장비, 특별 칭호
