# 생산 시스템 기획서

## 개요

생산 시스템은 전투와 별개로 캐릭터가 자원을 채집하고 아이템을 제작하는 시스템입니다.

**핵심 특징:**
- 캐릭터당 전투 클래스 1개 + 생산 클래스 1개
- 타이머 기반 (비동기)
- 레벨업 & 스킬 시스템
- 품질 보너스 (레벨에 따라)

---

## 1. 생산 직업 구조

### 1.1 직업 선택
- `/production` 명령어로 선택
- **한 번만 선택 가능** (변경 불가)
- 카테고리 선택 → 직업 선택

자원을 수집하는 직업

| 직업 | 이모지 | 채집 시간 | 주요 자원 |
|------|--------|-----------|-----------|
| 광부 | 🪨 | 30분 | 철/구리/은/금광석, 보석 |
| 약초꾼 | 🌿 | 25분 | 허브, 약초, 희귀/마법 허브 |
| 벌목꾼 | 🪓 | 20분 | 목재, 단단한/희귀/마법 목재 |
| 어부 | 🎣 | 30분 | 물고기, 희귀 물고기, 해산물, 진주 |
| 사냥꾼 | 🐾 | 40분 | 가죽, 고기, 모피, 뼈 |

#### ⚒️ 제작 계열 (4개)
자원으로 아이템을 만드는 직업

| 재봉사 | 🧵 | 20~40분 | 의류, 가방 |
| 요리사 | 🍳 | 10~20분 | 음식, 버프 음식 |

## 2. 통일된 직업 구조

모든 생산 직업은 동일한 구조를 가집니다:

### 2.1 기본 속성

```javascript
{
  key: 'job_key',           // 직업 고유 키
  name: '직업명',           // 표시 이름
  emoji: '🔨',             // 이모지
  category: 'gathering',    // gathering or crafting
  description: '설명',      // 직업 설명
  
  // 채집 직업
  gatherTypes: [...],       // 채집 가능한 자원
  baseGatherTime: 1800,     // 기본 채집 시간 (초)
  
  // 제작 직업
  craftTypes: [...],        // 제작 가능한 타입
  baseCraftTime: 3600,      // 기본 제작 시간 (초)
  
  // 공통
  levelBonus: {
    gatherSpeed: 0.05,      // 레벨당 속도 +5%
    quantity: 0.10,         // 레벨당 수량 +10%
    craftSpeed: 0.05,       // 레벨당 제작 속도 +5%
    quality: 0.02,          // 레벨당 품질 +2%
  }
}
```

### 2.2 레벨 시스템

**레벨별 요구 경험치:**
```
Lv.N → Lv.N+1 = 100 × 1.5^(N-1)

예:
Lv.1 → Lv.2: 100 XP
Lv.2 → Lv.3: 150 XP
Lv.3 → Lv.4: 225 XP
Lv.5 → Lv.6: 506 XP
Lv.10 → Lv.11: 3844 XP
```

**경험치 획득:**
- 채집 완료: 자원 티어 × 10 XP
- 제작 완료: 제작 시간(분) XP

**레벨업 보상:**
- 기본: 레벨 × 100G
- 5레벨마다: 레벨 × 50G 추가
- 10레벨: 생산 마스터 칭호
- 20레벨: 생산 대가 칭호

### 2.3 스킬 시스템

모든 직업은 2단계 스킬 구조:

#### Tier 1: 고급 스킬 (Lv.5)
```javascript
{
  key: 'advanced_[class]',
  name: '고급 [기술명]',
  requiredLevel: 5,
  cost: 600~1000G,        // 직업별 차이
  description: '희귀(T3) 아이템 제작 가능',
  unlocks: [...]          // 잠금 해제되는 레시피
}
```

#### Tier 2: 마스터 스킬 (Lv.10)
```javascript
{
  key: 'master_[class]',
  name: '[직업] 마스터',
  requiredLevel: 10,
  cost: 2000~3000G,       // 직업별 차이
  requires: ['advanced_[class]'], // 선행 스킬
  description: '영웅(T4) 아이템 제작 가능',
  unlocks: [...]          // 잠금 해제되는 레시피
}
```

**스킬 비용:**
| 직업 | 고급 | 마스터 |
|------|------|--------|
| 대장장이 | 1000G | 3000G |
| 연금술사 | 800G | 2500G |
| 재봉사 | 800G | 2500G |
| 요리사 | 600G | 2000G |

## 3. 자원 시스템

### 3.1 자원 티어

| 티어 | 희귀도 | 채집 수량 | 경험치 | 예시 |
|------|--------|-----------|--------|------|
| T1 | 일반 | 5개 | 10 XP | 목재, 철광석, 허브 |
| T2 | 고급 | 4개 | 20 XP | 단단한 목재, 약초, 가죽 |
| T3 | 희귀 | 3개 | 30 XP | 희귀 목재, 은광석 |
| T4 | 영웅 | 2개 | 40 XP | 마법 목재, 금광석, 보석 |

### 3.2 자원 획득 방법

1. **채집** (`/gather`)
   - 채집 직업 전용
   - 타이머 기반 (20~40분)
   - 레벨 보너스 적용

2. **전투 드롭**
   - 지역별 자원 테이블
   - 30~40% 드롭 확률
   - 1~3개 랜덤 수량

**지역별 드롭:**
| 지역 | 드롭률 | 자원 |
|------|--------|------|
| 초보자 숲 | 30% | 목재, 허브, 고기 |
| 어둠의 동굴 | 35% | 철/구리광석, 뼈, 가죽 |
| 죽음의 산맥 | 40% | 은/금광석, 희귀 약초, 모피 |

## 4. 제작 시스템

### 4.1 레시피 구조

```javascript
{
  key: 'recipe_key',
  name: '아이템명',
  emoji: '⚔️',
  type: 'weapon',           // weapon/armor/potion/food/cloth
  craftClass: 'blacksmith', // 제작 직업
  craftTime: 3600,          // 제작 시간 (초)
  requiredLevel: 1,         // 최소 생산 레벨
  requiredSkill: null,      // 필요 스킬 (선택)
  
  materials: {              // 필요 재료
    iron_ore: 5,
    wood: 2,
  },
  
  result: {                 // 결과물
    type: 'equipment',
    equipmentType: 'weapon',
    rarity: 'common',
    attack: 10,
    defense: 0,
    effect: null,           // 특수 효과
  }
}
```

### 4.2 품질 시스템

생산 레벨에 따라 스탯 증가:
```
최종 스탯 = 기본 스탯 × (1 + (레벨 - 1) × 0.02)

예:
Lv.1: 철 검 (공격 +8)
Lv.5: 정교한 철 검 (공격 +8.6)
Lv.10: 고급 철 검 (공격 +9.4)
```

**이름 접두어:**
- Lv.1~4: 기본
- Lv.5~9: "정교한"
- Lv.10+: "고급"

### 4.3 레시피 티어별 분류

#### T1 (일반) - 스킬 불필요
- 대장장이: 철 검, 철 갑옷
- 연금술사: 체력/마나 포션
- 재봉사: 가죽 장갑
- 요리사: 구운 고기

#### T2 (고급) - 스킬 불필요
- 대장장이: 강철 검
- 연금술사: 상급 체력 포션
- 재봉사: 모피 코트
- 요리사: 생선 스튜

#### T3 (희귀) - 고급 스킬 필요
- 대장장이: 은빛 검, 미스릴 갑옷
- 연금술사: 힘/방어 영약
- 재봉사: 마법 로브, 그림자 망토
- 요리사: 파워 스테이크, 수호자 스프

#### T4 (영웅) - 마스터 스킬 필요
- 대장장이: 드래곤 슬레이어, 전설의 판금
- 연금술사: 현자의 돌, 불멸의 영약
- 재봉사: 천상의 로브, 드래곤 비늘 갑옷
- 요리사: 왕의 연회, 드래곤 고기 스튜

## 5. 명령어 체계

### 5.1 기본 명령어

| 명령어 | 설명 |
|--------|------|
| `/production` | 생산 직업 선택 |
| `/gather` | 자원 채집 (채집 직업) |
| `/craft` | 아이템 제작 (제작 직업) |
| `/resources` | 보유 자원 확인 |
| `/production_skills` | 생산 스킬 확인 및 구매 |

### 5.2 프로필 통합

프로필 → 생산 버튼:
```
[채집] [제작] [자원] [스킬] [프로필]
```

생산 정보 표시:
- 현재 직업 & 레벨
- 경험치 진행도
- 보유 자원 수
- 진행 중인 작업 (타이머)

## 6. 균형 설계

### 6.1 시간 밸런스

**채집:**
- 최단: 20분 (벌목꾼)
- 최장: 40분 (사냥꾼)
- 평균: 28분

**제작:**
- 최단: 10분 (요리사 기본)
- 최장: 120분 (대장장이 T4)
- 평균: 40분

### 6.2 경제 밸런스

**스킬 비용:**
- 고급: 600~1000G (평균 800G)
- 마스터: 2000~3000G (평균 2600G)

**레벨업 보상:**
- Lv.1~10: 총 ~5500G
- Lv.1~20: 총 ~20000G

**제작 원가:**
- T1: ~100G 상당
- T2: ~500G 상당
- T3: ~2000G 상당
- T4: ~5000G 상당

### 6.3 진행 곡선

**초반 (Lv.1~5):**
- 기본 레시피 학습
- 자원 채집 숙달
- 첫 스킬 구매 목표

**중반 (Lv.5~10):**
- 고급 스킬 획득
- T3 레시피 제작
- 마스터 스킬 준비

**후반 (Lv.10+):**
- 마스터 스킬 획득
- T4 레시피 제작
- 최고 품질 아이템 양산
