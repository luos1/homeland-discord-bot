장비 시스템

4개 등급의 장비를 획득하고 강화하세요:

Common (일반) Uncommon (고급) Rare (희귀) Epic (영웅)
  • 장비 강화: 최대 +10까지 강화 가능 (성공률 65%)
  • 장비 가챠: 골드로 랜덤 장비 획득
  • 장비 판매: 불필요한 장비 판매

스킬 시스템

  • 기본 스킬: 각 클래스 고유 스킬
  • 상급 스킬: 레벨 5부터 상점에서 구매 가능 (5개)
  • 마스터 스킬: 보스 드랍 (2개)
  • 스킬 업그레이드: 100% 성공률

🛠️ 생산 시스템

💰 경제 시스템

자원 거래소

플레이어 간 자원을 자유롭게 거래할 수 있습니다.

  • 판매: 자원 등록 (수량 + 개당 가격 설정)
  • 구매: 등록된 자원 구매
  • 수수료: 판매 금액의 10%
  • 취소: 판매 취소 시 전액 환불

소모품 시스템

제작한 소모품을 사용하여 캐릭터를 강화하세요.

  • 포션: 체력/마나 회복
  • 음식: 일시적인 스탯 버프
  • 엘릭서: 강력한 버프 효과

골드 획득 방법

  • 전투 승리 시 골드 획득
  • 생산 레벨업 시 보상 (레벨 × 100G, 5레벨마다 +50G)
  • 장비 판매
  • 자원 거래

📝 주요 명령어

기본 명령어

/start - 게임 시작 및 클래스 선택
/profile - 캐릭터 정보 확인
/reset - 클래스 초기화 (HP/MP 전체 회복)

전투 명령어

/hunt [지역] - 전투 시작
/inventory - 인벤토리 확인
/shop - 상점 (장비 가챠, 강화, 판매)
/shop_skills - 스킬 상점

생산 명령어

/production - 생산 직업 선택
/gather - 자원 채집 시작
/craft - 아이템 제작 시작
/resources - 자원 인벤토리
/production_skills - 생산 스킬 상점

경제 명령어

/market - 자원 거래소

💡 초보자 가이드

게임 시작하기

  1. /start로 캐릭터 생성 및 클래스 선택
  2. /hunt 1으로 초보자 숲에서 전투 시작
  3. 골드를 모아 /shop에서 장비 구매
  4. 레벨 5가 되면 /shop_skills에서 스킬 구매

효율적인 플레이

  • 생산 직업 병행: /production으로 생산 직업을 선택하여 자원을 모으세요
  • 타이머 활용: 채집/제작 타이머를 활용하여 AFK 시간에도 자원을 모으세요
  • 거래소 활용: 필요한 자원은 /market에서 구매하세요
  • 장비 강화: 골드가 충분해지면 장비를 강화하여 전투력을 높이세요

주의사항

  • 클래스 변경 시 /reset을 사용하세요 (HP/MP 완전 회복)
  • 장비 강화는 실패할 수 있습니다 (65% 성공률)
  • 스킬 업그레이드는 100% 성공합니다
  • 거래소 판매 시 10% 수수료가 부과됩니다
