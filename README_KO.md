# Homeland Discord RPG Bot

Discord에서 즐기는 턴제 RPG 게임

## 🎮 주요 기능

### ⚔️ 전투 시스템
- **스킬 콤보**: 3스킬 연계로 4배 데미지
- **크리티컬**: 💥💥💥 CRITICAL HIT!! 💥💥💥
- **오토 배틀**: AI 자동 전투
- **연속 사냥 보너스**: 5연승 골드 2배, 10연승 경험치 2배

### 🎯 성장 시스템
- **레벨업 연출**: 화려한 애니메이션과 스탯 증가 시각화
- **장비 강화**: +15까지 강화, 실패 시 레벨 하락
- **직업 시스템**: 전사/궁수/마법사 + 상급 직업
- **스킬 트리**: 다양한 스킬 조합

### 👥 사회 시스템
- **길드**: 길드 생성, 관리, 레벨업
- **거래**: 플레이어 간 1:1 거래
- **PvP**: ELO 레이팅 기반 랭킹전
- **필드 보스**: 랜덤 등장, 전체 공지

### 📋 일일 콘텐츠
- **일일 퀘스트**: 매일 랜덤 3개 퀘스트
- **주간 랭킹**: 레벨/사냥/길드 순위
- **이벤트**: 시즌별 특별 이벤트

### 💎 프리미엄
- **Bronze ($5/월)**: XP/골드 +25%, 오토 10회/일
- **Silver ($10/월)**: XP/골드 +50%, 오토 30회/일, 전용 스킬
- **Gold ($20/월)**: XP/골드 +100%, 오토 무제한, 전용 던전

## 🚀 빠른 시작

### Discord Bot 초대
```
https://discord.com/api/oauth2/authorize?client_id=YOUR_CLIENT_ID&permissions=274878286912&scope=bot%20applications.commands
```

### 게임 시작
```
/play        # 캐릭터 생성
/village     # 마을 허브
/hunt        # 사냥 시작
/profile     # 내 정보
```
